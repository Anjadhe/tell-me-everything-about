Make this your home page

Copy this address, then paste it where your browser keeps the home page setting.

  • Chrome Settings, Appearance, turn on Show home button, paste the address. For start-up, Settings, On startup, Open a specific page.
  • Safari Settings, General, Homepage. Set New windows open with and New tabs open with to Homepage.
  • Firefox Settings, Home, Homepage and new windows, Custom URLs.
  • Arc Add it as a pinned tab, or make it the space's start page.

New tabs too? Safari has a setting for it. Chrome, Edge, Brave and Firefox need a small extension; ours is in the source, ready to load unpacked.
